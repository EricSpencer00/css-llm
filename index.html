what is actually running

CSS-RNN-32 is a trained character-level recurrent model. Its weights, hard-tanh activation, argmax, and 64-step recurrence live in css-model.css.

JavaScript only writes the seed into typed CSS properties and reads the computed character ids back. There is no server, worker, WASM, or model download.
