The intern assignment

Five facts. One real model.

Tap a row to inspect what is actually happening.

01SmolLM2-135M-InstructA 135M-parameter text-generation model from Hugging Face.real weights

This page uses the ONNX export of SmolLM2-135M-Instruct through Transformers.js. It is a text-only small language model, not a multimodal one.

02Runs on your hardwareWebGPU when available, WebAssembly when it is not.browser-local

The browser downloads the model files from the Hugging Face Hub, then executes generation locally in a worker. No prompt is sent to an inference API.

03ONNX Runtime WebTransformers.js runs the exported model in the browser.actual runtime

CSS is presentation here. The model execution is performed by ONNX Runtime Web, selected by Transformers.js.

04Streaming outputGenerated tokens appear as the model produces them.measured live

The output panel is fed by a TextStreamer in the worker. The latency readout is measured from the button press to generation completion.

05Weights cache in this browserThe first load is heavy; later visits reuse the cached files.no backend

The runtime uses the browser cache for model assets. Clear site data and the next visit will need to download them again.

CSS is Turing complete*

* no backend required. model files download on first run.
