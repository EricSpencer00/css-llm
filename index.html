The intern assignment

Five facts. One CSS model.

Tap a row to inspect what is actually happening.

01CSS-RNN-3232 hidden units and a 32-character vocabulary.trained weights

This is a trained character-level recurrent language model, not a lookup table. It predicts the next character from the previous hidden state and character.

02Weights are CSSFloat32 weights are numeric literals inside css-model.css.CSS payload

The stylesheet contains the learned matrices and biases as operands in CSS custom-property declarations. There is no model download or runtime library.

03Style engine inferenceCSS custom properties carry the neural dataflow.actual runtime

A hidden engine element carries typed numeric properties. The browser resolves sums, hard-tanh activations, comparisons, argmax, and recurrent dependencies as computed style.

04Fixed-shape autoregression24 seed characters become 64 greedy generated characters.unrolled graph

The graph is finite because CSS needs a fixed topology. Each generated argmax becomes the next one-hot input, so the rollout is model recurrence rather than a canned answer.

05JavaScript is I/O onlyIt binds the seed and reads computed character ids.bridge only

JavaScript does not hold the weights or perform matrix math. It maps typed characters to CSS input properties and maps the CSS output properties back to displayable characters.

CSS is Turing complete*

* no backend. css-model.css contains the model.
